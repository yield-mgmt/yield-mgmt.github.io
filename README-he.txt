YIELD - אתר דף נחיתה (עברית + אנגלית) - מוכן להעלאה
=====================================================

האתר סטטי לגמרי: אין שרת, אין מסד נתונים, אין שירותים חיצוניים ואין עוגיות.
הפונט (Heebo, רישיון OFL) כלול בחבילה, ולכן אין פנייה לשרתי Google.
אין בו שנה או תאריך שדורשים עדכון שנתי.

העלאה ל-GitHub Pages
--------------------
1. הרשם ל-GitHub עם שם משתמש: yield-mgmt (אם תפוס, עצור ופנה אליי לבניה מחדש עם שם אחר).
2. צור מאגר ציבורי (Public) בשם בדיוק: yield-mgmt.github.io  (בלי README).
3. Add file > Upload files, וגרור את תוכן התיקייה yield-site (כולל התיקיות assets ו-en
   והקובץ .nojekyll). אל תעלה שום דבר אחר: המאגר ציבורי וכל קובץ בו חשוף.
4. Commit changes.
5. Settings > Pages > Source: Deploy from a branch > Branch: main, תיקייה /(root) > Save.
6. אחרי דקה-שתיים האתר עולה בכתובת https://yield-mgmt.github.io/ (אנגלית ב-/en/).
   סמן Enforce HTTPS בדף Pages.
7. מומלץ: ב-Google Search Console הוסף את הכתובת ושלח את sitemap.xml.

הכתובת כבר מוטמעת בקבצים (canonical, hreflang, sitemap, תמונת שיתוף). אם תשנה את שם
המשתמש, יש לבנות את החבילה מחדש.

תחזוקה
------
בדרך כלל אין. מה שיכול להשתנות:
- קישור היומן, טלפון או מייל: חפש ב-index.html וב-en/index.html את הערך הישן והחלף בשניהם.
  (קישור היומן מופיע גם ב-llms.txt.)
- שינוי טקסט: עריכה ישירה בשני הקבצים.

מה כדאי לבדוק לפני העלאה (באחריותך)
-----------------------------------
- המלצות הלקוחות: אישור בכתב לפרסום השם, התפקיד והציטוט.
- פטור מנגישות: מותנה בהיקף הפעילות ובסוג העוסק. מומלץ לוודא מול רואה החשבון.
- תנאי השימוש של GitHub Pages אינם מתירים הפעלת עסק מקוון מסחרי. דף תדמית הוא אזור אפור
  ללא אישור רשמי. אם חשוב לך ודאות, פנה לתמיכת GitHub. חלופות חינמיות: Cloudflare Pages או
  Firebase Hosting, והחבילה עובדת בהן בלי שינוי.
